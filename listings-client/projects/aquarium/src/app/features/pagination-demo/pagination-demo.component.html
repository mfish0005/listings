Pagination Component

Numbered page navigation that collapses long ranges with ellipses. It follows the active theme through the published CSS variables.

Basic Usage

Bind the current page and the total number of pages. The component emits the requested page and leaves the data loading to you.

Current page: {{ basicPage() }}
<fish-pagination
  [page]="page()"
  [totalPages]="5"
  (pageChange)="page.set($event)">
</fish-pagination>

Many Pages

Pages far from the current one collapse into ellipses. The first and last pages always stay reachable.

Current page: {{ manyPage() }} of 40

Sibling Count

Controls how many pages are shown on each side of the current page.

<fish-pagination [page]="page()" [totalPages]="40" [siblingCount]="2"></fish-pagination>

Disabled

Use while a request is in flight to prevent overlapping page changes.

Single Page

Nothing renders when there is only one page, so no conditional is needed in the consuming template.

The pagination above renders nothing

API

page number Current page, starting at 1. Defaults to 1.
totalPages number Total number of pages. Nothing renders when it is 1 or less.
siblingCount number Pages shown on each side of the current page. Defaults to 1.
disabled boolean Blocks all page changes. Defaults to false.
pageChange EventEmitter<number> Emits the requested page.
