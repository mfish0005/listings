Theming

Customize Fish UI with SCSS variables. Override any variable with !default before importing fish-styles.

Quick Theme Setup

Create a theme file and override any variables you need:

src/styles/themes/my-theme.scss 
// Most Common Color Overrides
$primary: #007bff;        // Main brand color
$secondary: #6c757d;      // Secondary color
$success: #28a745;        // Success states
$danger: #dc3545;         // Error states
$warning: #ffc107;        // Warning states

// Typography Overrides
$family-sans-serif: 'Inter', 'Segoe UI', sans-serif;
$family-primary: $family-sans-serif;
$size-6: 1rem;           // Base text size
$size-7: 0.875rem;       // Small text size

// Gray Scale Overrides
$gray-lightest: #f8f9fa;  // Very subtle backgrounds
$gray-lighter: #e9ecef;   // Card backgrounds
$gray-light: #dee2e6;     // Borders and dividers
$gray: #6c757d;           // Secondary text
$gray-dark: #495057;      // Icon colors
$gray-darker: #343a40;    // Placeholder text
$gray-darkest: #212529;   // Primary text

// Import fish-styles AFTER your overrides
@import '~fish-ui/styles/fish-styles/all';
example.component.scss 
// Import your theme where it's needed.
@import './themes/my-theme';
src/styles.scss (global styles, once) 
@import './styles/themes/my-theme';

// Publish the theme so library components can use it
@include fish-theme-vars;
💡 That's it! Override just the variables you need. All variables use !default, so your overrides take precedence.

How Components Are Themed

Components are compiled with the library, so they cannot see your Sass variables. Sass variables are the authoring API and CSS custom properties are the runtime contract. fish-theme-vars publishes every token in the $fish-tokens registry as a --fish-* property, and components and helper classes read those properties.

Compiled component CSS 
background-color: var(--fish-primary);
font-family: var(--fish-family-primary);
Published by fish-theme-vars 
--fish-primary: #00bcd4;
--fish-primary-dark: color-mix(in srgb, var(--fish-primary), black 15%);
  • The include is required setup. Components have no per-declaration fallback, so without it colors are missing.
  • Include fish-theme-vars once, in global styles, after importing fish-styles.
  • Scope a theme with a selector: @include fish-theme-vars('.dark-section');
  • Hover shades (primary-dark and the other *-dark tokens) follow their base color live, unless your theme sets one by hand.
  • Change a theme at runtime with document.documentElement.style.setProperty('--fish-primary', '#0f766e').
  • Component styles import fish-styles/tools (no CSS output), never all. Read colors with fish-color("primary") and fonts with fish-font("family-primary"), and use fish-alpha("primary", 10%) instead of rgba().
  • In app styles, use the tokens for anything that should follow a scoped or runtime theme, such as background-color: fish-color("gray-lightest").

Complete Theme Example

Here's a comprehensive theme file showing all overrideable variables:

src/styles/themes/complete-theme.scss 
// COLORS - Override base colors
$white: #ffffff;
$black: #1a1a1a;
$gray-lightest: #f8f9fa;
$gray-lighter: #f5f5f5;
$gray-light: #eeeeee;
$gray: #e0e0e0;
$gray-dark: #bdbdbd;
$gray-darker: #9e9e9e;
$gray-darkest: #757575;

// Base color palette
$green: #28a745;
$green-light: #51cf66;
$green-dark: #1e7e34;

$blue: #007bff;
$blue-light: #4dabf7;
$blue-dark: #0056b3;

$red: #dc3545;
$red-light: #ff6b6b;
$red-dark: #bd2130;

$orange: #fd7e14;
$orange-light: #ffd43b;
$orange-dark: #e8590c;

$yellow: #ffc107;
$yellow-light: #fff3cd;
$yellow-dark: #e0a800;

$purple: #6f42c1;
$purple-light: #a98eda;
$purple-dark: #4c0d95;

// SEMANTIC COLORS - For consistent theming
$primary: $blue;
$secondary: $gray;
$success: $green;
$warning: $orange;
$danger: $red;
$info: $blue;
$text: $gray-darkest;

// TYPOGRAPHY - Font families and sizes
$family-monospace: 'JetBrains Mono', 'Fira Code', monospace;
$family-sans-serif: 'Inter', 'Segoe UI', sans-serif;
$family-primary: $family-sans-serif;
$family-secondary: $family-monospace;

// Font sizes (responsive scale)
$size-1: 3rem;     // 48px - Hero titles
$size-2: 2.25rem;  // 36px - Page titles
$size-3: 1.875rem; // 30px - Section headings
$size-4: 1.5rem;   // 24px - Subsection headings
$size-5: 1.25rem;  // 20px - Large text
$size-6: 1rem;     // 16px - Base text
$size-7: 0.875rem; // 14px - Small text

// Font weights
$weight-light: 300;
$weight-normal: 400;
$weight-semibold: 500;
$weight-bold: 700;

// Size array for helper classes
$sizes: $size-1, $size-2, $size-3, $size-4, $size-5, $size-6, $size-7;

// COLOR MAPS - Used by helper classes (.has-text-*, .has-background-*)
$colorMap: (
  "white": $white,
  "black": $black,
  "primary": $primary,
  "secondary": $secondary,
  "success": $success,
  "warning": $warning,
  "danger": $danger,
  "info": $info,
  "green": $green,
  "blue": $blue,
  "red": $red,
  "orange": $orange,
  "yellow": $yellow,
  "purple": $purple,
  "gray": $gray,
);

// SHADE MAPS - Used for hover states and variations
$shadeMap: (
  "gray-lightest": $gray-lightest,
  "gray-lighter": $gray-lighter,
  "gray-light": $gray-light,
  "gray-dark": $gray-dark,
  "gray-darker": $gray-darker,
  "gray-darkest": $gray-darkest,
  "green-light": $green-light,
  "green-dark": $green-dark,
  "blue-light": $blue-light,
  "blue-dark": $blue-dark,
  "red-light": $red-light,
  "red-dark": $red-dark,
  "orange-light": $orange-light,
  "orange-dark": $orange-dark,
  "yellow-light": $yellow-light,
  "yellow-dark": $yellow-dark,
  "purple-light": $purple-light,
  "purple-dark": $purple-dark,
);

// Import fish-styles AFTER all overrides
@import '~fish-ui/styles/fish-styles/all';
